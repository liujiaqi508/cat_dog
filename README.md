# 猫狗图像二分类系统
本项目基于PyTorch深度学习框架，采用ResNet18预训练卷积神经网络实现猫狗图像二分类任务。项目完整实现了数据集训练、模型验证、训练过程可视化、结果曲线绘制以及Gradio网页在线预测功能，并使用Git进行完整版本管理，全部代码托管于GitHub远程仓库，项目结构规范、流程完整，可直接复现运行。

## 一、项目文件结构
本项目包含完整训练、预测、绘图、依赖配置与说明文档，所有文件如下：
- train.py：模型训练主程序，负责数据集加载、模型训练、参数更新、最佳模型保存
- predict.py：网页预测程序，基于Gradio搭建可视化界面，支持上传图片实时识别猫狗类别
- draw_plot.py：训练结果可视化脚本，根据训练日志生成Loss损失曲线与准确率曲线
- requirements.txt：项目全部依赖库清单，支持一键批量安装环境
- train_result.png：模型训练完成生成的训练损失与验证准确率曲线图
- README.md：项目完整说明文档
- .gitignore：Git忽略文件配置，自动过滤缓存文件、虚拟环境、模型权重等冗余文件

## 二、数据集介绍
本项目采用猫狗二分类小型数据集，总计100张图片，其中猫类图片50张、狗类图片50张。数据集按照训练集与验证集比例划分，训练集与验证集数据相互独立、无重叠，保证模型评估结果真实可靠。数据集数量适中，适合深度学习图像分类模型基础训练与教学实验。

## 三、开发环境与依赖配置
项目采用Anaconda搭建独立虚拟环境，隔离所有依赖包，保证项目可移植、可复现。
主要依赖库版本：
torch、torchvision、opencv-python、gradio、matplotlib

可通过requirements.txt一键安装全部依赖，无需手动逐条配置，环境搭建高效便捷。

## 四、项目核心功能
1. 基于ResNet18预训练模型迁移学习训练，利用成熟网络结构提升小型数据集训练精度与收敛速度。
2. 完整训练流程，包含迭代训练、误差计算、参数更新、最佳模型自动保存。
3. 训练数据可视化，自动绘制训练损失下降曲线与验证集准确率变化曲线，直观展示模型收敛状态。
4. 基于Gradio快速搭建无代码前端网页，支持本地浏览器上传图片、实时推理、输出分类结果与置信度。
5. 完整Git版本控制管理，对代码、文档、曲线图进行版本记录与云端托管。

## 五、训练过程与实验结果
本项目共设置10轮迭代训练，模型训练收敛效果良好。训练过程中训练损失持续下降，模型不断拟合数据特征。首轮训练验证准确率达到95%，为模型最佳精度，后续训练验证准确率稳定维持在90%左右。

由于本项目数据集样本数量较少，模型存在轻微过拟合现象，属于小样本训练正常现象。整体模型分类效果优秀，能够准确区分猫、狗两类图像特征，完成二分类任务。

## 六、项目运行流程
1. 克隆GitHub仓库代码至本地
2. 创建并激活Conda虚拟环境
3. 通过requirements.txt安装全部依赖库
4. 运行train.py完成模型训练，自动生成最佳权重文件
5. 运行draw_plot.py生成训练结果曲线图
6. 运行predict.py启动网页预测界面，上传图片完成智能分类
